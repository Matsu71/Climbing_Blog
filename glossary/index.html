記録・観戦

ベータBeta
課題を解くための手順や、登り方についての情報です。
他人のベータが、そのまま自分の体型に合うとは限りません。
関連する記事 →
核心Crux
課題の中で特に難しい一手、または一連の動きです。
核心ができることと、最初からつなげられることは別です。
関連する記事 →
フラッシュFlash
事前の情報を得ていても、最初のトライで完登することです。
「今日の1回目」ではなく、その課題への最初のトライです。
関連する記事 →
オンサイトOn-sight
登り方の事前情報を得ずに、初見の1回でルートを完登することです。
フラッシュと分けて記録します。
関連する記事 →
レッドポイントRedpoint / RP
ルートを事前に試したうえで、落下やロープに頼る休息なしにリードで完登することです。
RPはルート登攀の記録用語です。ボルダーでは完登・フラッシュを区別します。
関連する記事 →
グレードGrade
課題やルートの難しさを表す評価です。
筋力の単位ではありません。種目や評価体系を添えて読みます。
関連する記事 →

施設・種目

ボルダーBouldering
ロープを使わず、比較的低い岩や壁で行うクライミングです。
低い壁でも着地の危険があります。施設の安全指導を優先します。
関連する記事 →
リードLead climbing
登りながらロープを支点に通し、下のビレイヤーに確保される登り方です。
この説明だけでは実施できません。実地の指導と安全確認が必要です。

ホールド

ジャグJug
手で掛かりを捉えやすい、大きなホールドです。
持ちやすくても、次の動きや足位置が簡単とは限りません。
関連する記事 →
スローパーSloper
指を深く掛けにくい、丸い面を持つホールドです。
同じホールドでも、力を加える向きによって条件が変わります。
関連する記事 →
エッジEdge
指先やシューズの縁を載せる、小さな段差です。
保持測定ではエッジの奥行きや形状も記録します。
関連する記事 →

ムーブ

スメアSmearing
明確な足場だけに頼らず、シューズと面の摩擦で支える使い方です。
「面積を増やせば必ず止まる」とは限りません。
関連する記事 →
フラッグFlagging
空いている脚などを使い、身体の回転を抑える動きです。
脚の形だけでなく、どちらに回ろうとしているかを考えます。
関連する記事 →
バックステップBack step
足の外側のエッジを使い、腰を横向きにする動きです。
届きやすさと、次の一手へ移れるかを両方比べます。
関連する記事 →
ドロップニーDrop knee
足を置いたまま膝を内側・下向きへ動かし、腰の向きを変える動きです。
膝を無理にねじる練習にはしません。痛みがあれば中止します。
関連する記事 →
マントルMantle
手で下向きに押し、身体を上へ乗り込ませる動きです。
最後の乗り込みや下降まで含めて安全を確認します。
関連する記事 →
サイドプルSide pull
横方向へ引いて使うホールド、またはその使い方です。
反対向きの力を、足やもう一方の手でどう作るかが重要です。
関連する記事 →
アンダークリングUndercling
ホールドの下側を持ち、上向きに引く使い方です。
手だけでなく、足から押す向きと身体の高さを見ます。
関連する記事 →
ガストンGaston
肘を外へ向け、手を外側へ押し広げるように使う動きです。
形を再現することと、安全に負荷を受けられることは別です。
関連する記事 →

力学

モーメントMoment / torque
力が物体を回そうとする作用です。力の大きさと作用線からの距離が関係します。
同じ力でも、支点からの距離が変わると回転への作用が変わります。
関連する記事 →
法線力Normal force
接触している面に垂直な向きの力です。
鉛直方向とは限りません。傾いたホールドでは向きも変わります。
関連する記事 →
摩擦係数Coefficient of friction
単純な摩擦モデルで、法線力と摩擦の上限を結びつける係数です。
皮膚や岩の状態を無視した万能な定数ではありません。
関連する記事 →
静的な釣り合いStatic equilibrium
静止した物体で、力とモーメントの合計がそれぞれ釣り合う状態です。
動いている最中のキャッチを、そのまま同じ模型で予測しません。
関連する記事 →

身体・研究

エイプインデックスApe index
身長と、両腕を広げた長さの関係を表します。差または比で示されます。
差のcmと比の数値を混ぜて比較しません。
関連する記事 →
ランダム化比較試験Randomized controlled trial / RCT
対象者を無作為に群へ分け、介入による結果の違いを比べる研究です。
小標本や測定条件の限界が消えるわけではありません。
関連する記事 →
横断研究Cross-sectional study
ある時点の人や集団を測り、特徴同士の関係を調べる研究です。
体型と成績の関連だけでは、体重を変える効果は分かりません。
関連する記事 →
系統的レビューSystematic review
あらかじめ決めた方法で研究を集め、根拠を整理する手法です。
元の研究の質や、結果ごとの確実性も確認します。
関連する記事 →
プレプリントPreprint
査読前などの段階で公開された論文原稿です。
査読済み論文と同じ確実性として扱わず、改訂にも注意します。
