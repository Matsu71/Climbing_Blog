# 企画メモ：似ているクライミングシューズを探せる多軸マップ

- 記録日：2026-10-13
- 対象：CRUX（Climbing_Blog）
- 状態：記事・可視化の構想メモ。調査・採点・実装は未着手
- 関連：`docs/ideas/additional-topic-backlog.md` の「クライミングシューズ・ギア」

## 1. 発想・目的

「今履いているシューズは足に合っているが、別のシューズを試したい」「似た履き心地・性能のシューズを探したい」という人のために、**クライミングシューズ同士の足型と性能の類似性をグラフで比較できる記事・機能**を作る。

従来の単純なレビュー一覧やランキングではなく、シューズごとの位置関係・距離・グループを直感的に把握できることを重視する。

## 2. まず作りたい2軸の四象限マップ

**横軸：足型（細足向け ← → 幅広足向け）**  
**縦軸：ソール・シューズ全体の柔らかさ（柔らかい ← → 硬い）**

- 各シューズを平面上の1点（銘柄・モデル名付き）として表示
- 四象限で大まかなタイプを分け、近い場所にあるシューズを一目で確認
- 点を選択すると、メーカー・モデル、特徴、根拠、似ている候補を確認できる
- 「似ている」ものを視覚的にグループ化。ただし近い座標＝必ずしも同じフィット感・性能ではない
- 単一の二軸だけでは捉えきれない違いも説明する

この配置は**現時点で仮説**。実機比較・仕様・レビューなどの出典を確認するまで、具体的な製品を勝手に数値化しない。

## 3. 足型の類似性と性能の類似性を分ける

### A. 足型・フィット感（形の近さ）

候補指標：
- 前足部の幅（狭い〜広い）
- かかとの幅・深さ
- 甲の高さ・足囲・ボリューム
- つま先形状（エジプト型・ギリシャ型等との相性）
- トウボックス形状・母趾側への寄せ方
- サイズ選び・伸びの傾向（サイズ／モデル・版ごとの差を考慮）

### B. 性能・履き心地（使い方の近さ）

候補指標：
- 柔らかさ／剛性（前足部の曲げやすさと全体の支持性は必要に応じて分離）
- スメアリング・ボリュームへの適性
- エッジング性能
- ダウントゥの強さ・非対称性
- 足裏感覚
- トウフック／ヒールフックの設計・適性
- 想定用途（スラブ／垂壁／強傾斜、インドア／外岩、ボルダー／リード等）

同じ足型でも性能が違うシューズ、性能が似ていても足に合わないシューズを区別する。「足型が似ている順」「性能が似ている順」を切り替えて探索できると価値が高い。

## 4. 将来的な可視化案

1. **基本の2D散布図**：幅の狭さ〜広さ × 柔らかさ〜硬さ
2. **軸を変更できる散布図**：例「スメアリング × エッジング」「前足部幅 × かかと幅」
3. **色・形・サイズで第3・第4の情報を表現**：ブランド、得意分野、ダウントゥなど（凡例必須）
4. **類似モデルのおすすめ表示**：選択した1足に近い候補を上位表示し、似ている理由と異なる点を明示
5. **詳細な多次元分析**：標準化した特徴量から距離やクラスタを計算。必要ならPCA/UMAP等の2D投影も検討（投影軸の意味と情報損失を説明）
6. **比較モード**：現在履いているモデルと候補モデルを並べて表示

まずは理解しやすい四象限マップを優先。高次元の数理手法や推薦順位は、充分に検証可能なデータが揃った後に検討する。

## 5. 読者の想定利用シーン

- 「今のシューズは足型が合う。近い形状の別ブランドを見たい」
- 「今のシューズと同じくらい柔らかく、もう少し細身のモデルを探したい」
- 「スメアリング重視だが、エッジングも少し強いものが欲しい」
- 「足に合う候補から、ボリューム向けの1足を選びたい」

## 6. データの集め方・信頼性

- メーカー公式のラスト、フィット、構造・素材等の説明を一次情報として収集
- 独立した実測・専門レビュー・複数の利用者レビューで補強。**公式の設計上の意図と実際の着用感は別情報**として扱う
- 「幅広」「柔らかい」等は比較条件（サイズ、モデルの年度・仕様変更、着用状況）に左右されるため、評価基準を先に定義する
- 主観的な特徴は単一の断言や精密な数値として示さず、評価者数・合意度・信頼度を記録
- 各指標に出典URL、確認日、元表記、数値化方法、未確認（null）を保存。採点基準・版は後で更新できる設計にする
- シューズの相性は個人の足型・サイズ・好みで変わるため、可視化や類似性は試着の代替とは言わない
- 掲載画像は利用許諾・権利・出典表示を確認

## 7. 記事・機能の初期構成（案）

1. なぜ「似たシューズ」を探すのが難しいのか
2. 柔らかさ × 足幅の四象限マップ
3. 「足型が似ている」と「性能が似ている」の違い
4. マップの使い方：手持ちの1足から次の候補を探す
5. 比較候補の一覧と、似ている点・違う点
6. 出典、評価方法、限界と試着時の注意

**最小プロトタイプ**：対象モデルを少数に絞り、検証済みの属性だけで2D図＋説明を作る。根拠が不十分な項目は空欄のまま。記事として価値を確認してからデータと軸を増やす。
