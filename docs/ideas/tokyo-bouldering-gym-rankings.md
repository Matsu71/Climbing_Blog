- 位置づけ：CRUXの「クライミングジム」情報（所在地・設備・評価・地図）を活用する記事群

## ユーザー提案の概要

東京都内などのボルダリングジムを、利用者の目的別に選べるおすすめランキング記事を作成する。

想定記事：
1. **初心者向け**：初回利用・体験しやすいおすすめジム
2. **経験者向け**：課題の質、壁の多様性、トレーニング環境などを重視するおすすめジム
3. **遠征向け**：遠方から訪れて登る価値、アクセス、複数ジムの回りやすさ等を重視するおすすめジム
4. **海外からの来訪者向け**：訪日クライマー向け。言語案内、予約・支払い、アクセス、レンタルや利用方法のわかりやすさを重視するおすすめジム

目的ごとに評価軸が異なるため、**総合順位を1種類だけ作らず、目的別ランキングを分ける**。将来的には条件別フィルター、比較表、地図表示にも展開する。

## 評価候補（調査前の仮説）

| 分類 | 主な比較軸 |
|---|---|
| 初心者向け | 初回説明・講習、初心者課題、レンタル用品、料金、混雑情報、アクセス |
| 経験者向け | セットの質と更新頻度、課題の幅、強傾斜・スラブ等の壁構成、設備・トレーニング環境 |
| 遠征向け | そのジムならではの特徴、課題の充実度、駅からのアクセス、日帰り・周遊のしやすさ、ビジター利用条件 |
| 海外からの来訪者向け | 英語等の案内、当日利用可否、支払い手段、レンタル、交通アクセス、外国人旅行者向けの利用手順 |

全分類に共通する項目：所在地、公式URL、営業時間、定休日、料金、初回登録料、利用条件、最寄り駅、設備、確認日。

## 採点・編集に関する原則

- ジム名・実際の順位・点数は**調査と根拠確認後**に決定する。現段階では仮順位を作らない。
- 「おすすめ」は目的別に基準と重みを明示し、確認できた事実と実地体験・主観的レビューを分ける。
- ジム公式サイト等の一次情報で営業時間、価格、レンタル、利用条件、言語対応を確認し、参照URLと確認日を保持する。
- 設備やグレード傾向など変更されうる情報は定期更新を前提とし、不明事項は不明と記録する。
- 口コミ・レビューを用いる場合は出典、件数、集計時点、偏りを明示する。
- 許可なく写真・レビュー本文を転載しない。
- 同じ施設データをランキング・比較表・検索・地図に再利用できるよう、可能な限り構造化して管理する。
- **現在の「出典付きデータの収集・検証を記事量産より優先する」方針は変更しない。** 本メモは将来の記事候補であり、直ちに執筆・公開する指示ではない。
