# Climbing Blog / Site Vision

## 2026-09-14の優先方針

最終目標は世界一のクライミングブログ。現在は記事制作より、選手の身体数値・高難度登攀・怪我の治療研究の出典付きデータ収集を優先する。データの拡充が十分に終わっていない段階で記事を量産しない。

既存のChatGPT製構成は良くないものと仮定して見直す。関連の既存サイトを広く調べて参考先を明示し、情報構造・配色・見出しの短さを取り入れる。長い抽象的な宣伝文句を置かない。詳細は [データ優先の再設計](data-first-2026-09-14.md) を参照。

## 最終目的

このプロジェクトは、単なる個人ブログではなく、一般のクライマーが「知りたい」「比較したい」「調べたい」と思う情報を、公開情報・競技データ・学術研究・公式記録から可能な限り整理し、分かりやすく再構成する総合クライミング情報サイトを目指す。

目標は、インターネット上のクライミング関連サイトの中で、少なくとも次の観点で世界最高水準を目指すこと。

1. 分かりやすさ
2. 使いやすさ
3. データの整理度
4. 根拠・出典の明確さ
5. 可視化の質
6. 一般クライマーにとっての実用性
7. 複数テーマを横断して調べられる網羅性

「世界ナンバーワン」は宣伝上の自己評価ではなく、継続的な比較・改善目標として扱う。

## 主な想定ユーザー

中心ユーザーは、すでにクライミングをしている一般クライマー。

初心者向けコンテンツも用意するが、サイト全体を初心者入門サイトにはしない。経験者が何度も戻ってきて、データベース、比較、分析、トレーニング、怪我、難易度などを調べられることを重視する。

### ユーザーが強く関心を持ちやすいテーマ

- 誰がどの程度強いのか
- 世界最高難度は何か
- V15 / V16 / V17、9a / 9b / 9c等を誰が何本登っているか
- 自分の体型や身体能力はクライミングにどう影響するか
- 強くなるには何を鍛えるべきか
- 週何日登るのがよいか
- Hangboard、Campus Board、筋力トレーニングはどう使うか
- 休養は何日必要か
- 指、肩、肘、足首等の怪我をどう考えるか
- 怪我からどう復帰するか
- 競技ボルダーの課題は昔と今でどう変わったか
- どのジムがどこにあり、どのような設備・特徴があるか
- 世界の高難度課題はどこにあるか

## やらないこと / 優先しないこと

### ローカル岩場ガイドの完全代替
世界中の一般難度の全課題、アプローチ、駐車位置、ローカルルール等を完全網羅することは主目的にしない。

理由：
- 件数が非常に多い
- ローカル情報の更新頻度が高い
- 地域サイト、トポ、専用サービスの方が強い
- アクセス問題や非公開情報への配慮が必要

アウトドアでは、世界の高難度帯、歴史、人物、難易度推移、地理、スタイル等の「世界規模で集約する価値がある情報」を優先する。

## サイトの主要領域

### 1. クライマー・能力・身体データ
身長、体重、BMI、Ape Index、競技成績、外岩実績、最高グレード等を整理し、競技・外岩・男女・カテゴリー別に比較する。

### 2. 難易度・高難度クライミング
世界の高難度ボルダー / リード、初登史、再登、グレード変遷、クライマー別完登数、地図等。

### 3. トレーニング
研究、コーチング知見、選手実例、負荷管理を整理し、一般クライマーが使える形にする。

### 4. 怪我・予防・復帰
指を中心に、肩、肘、手首、膝、足首、足部等を研究ベースで整理する。

### 5. クライミングの力学
保持、摩擦、重心、壁角度、モーメント、身体位置、ホールド形状等を物理・生体力学から解説する。

### 6. 競技課題分析
公式大会動画から課題要求能力、壁角度、ホールド、ムーブ、トップ率等をデータ化し、年代変化を分析する。

### 7. クライミングジム
日本のジムを中心に、所在地、設備、規模、開閉店、評価等を整理し、地図・時系列として見られるようにする。

### 8. 初心者向け
少数でも質の高い導入記事を用意する。

例：
- 初めてクライミングジムへ行く前に知ること
- ボルダリングの基本ルールと安全
- グレードの読み方
- 最初の3か月で意識すること
- シューズ、チョーク等の最低限の道具

## 「記事」より「再利用できるデータ」を優先する

可能なテーマは、記事本文だけを書いて終わらせず、元データをJSON / CSV等の構造化データとして保持する。

同じデータから、
- 一覧
- ランキング
- 年表
- 地図
- グラフ
- 個別記事
- 比較ページ
を生成できる状態を目指す。

## 情報収集の原則

優先順位：
1. 公式記録・本人発信・一次情報
2. 学術論文・レビュー・学会等
3. 競技団体・大会公式情報
4. メーカー・ジム等の公式情報
5. 信頼性の高い専門メディア
6. 二次情報・コミュニティ情報

重要データには、可能な限り出典URL、確認日、情報源種別、信頼度を保持する。

## UX原則

- 結論を先に示す
- 専門知識なしでも概要が分かる
- 詳細を知りたい人は深掘りできる
- 表とグラフを過剰に詰め込まず、比較軸を明確にする
- スマートフォンで使いやすいことを優先する
- 絞り込み、検索、並べ替えをできるだけ提供する
- 同じ情報を複数ページで矛盾させない
- 数値には定義、期間、母集団を明示する
- 不明・推定・議論中の情報は断定しない

## 評価指標

競合サイトとの比較では、以下を定期的に評価する。

- 必要な情報に到達するまでの操作数
- モバイルでの可読性
- データ件数とカバー範囲
- 出典付きデータ率
- 更新日が明確なデータ率
- 欠損値率
- 誤情報・重複率
- 検索 / フィルタ / 地図の使いやすさ
- 一般クライマーが実際に知りたい問いへの回答率

## 最終像

「クライミングについて何か調べたいとき、とりあえずここを見る」と思われるサイトを目指す。

ニュース速報サイト、ローカル岩場ガイド、単なるブログ、単なる選手名鑑のどれか一つには寄せず、公開データを整理・検証・可視化することで価値を作る。
