## 新しい構成

ホームの主入口は「選手の体格」「登攀記録」「怪我の研究」の3つ。記事、トレーニング研究、ジム、用語、トライノート、計算ツールは二次導線で残す。既存のテスト済み記事・機能は削除せず、新しいデータと相互リンクする。

- `/athlete-data/`：選手名検索、確認済み項目・出典差のフィルター、出典別の身長・体重・リーチ。
- `/ascent-data/`：課題名・人物検索、種目・スタイル・情報源のフィルター、日付の精度、評価の帰属、別バージョンの注意。
- `/injury-data/`：部位・資料種別のフィルター、対象→治療・比較→結果→限界。医学監修未実施の明示。
- `/evidence/`：33出典の台帳、採録範囲、未収集キュー、レイアウト参考先。

出典リンクは対応する台帳項目へ直接移動して開く。身体数値の食い違いは隠さず、別行の掲載値として提示する。現在の値・最新世界ランキングと誤読させない。

## 見出し・文章量

UIの編集目安：ナビゲーションは2〜8文字、節見出しは14文字程度、ページタイトルは28文字程度を優先する。固有名詞や明確さのため必要なら例外を認める。文字数だけを機械的に最小化しない。

| 避ける表現 | 採用した表現 |
|---|---|
| 登るほど、知りたくなる。 | クライミングデータ |
| 数字をもっと面白く。 | 記録の読み方 |
| 次の問いへ。 | 関連記事 |
| 読んだ先に、もう一つ。 | 関連ツール |
| 出典を通じて身体と登攀の可能性を切り開く | 選手の身長・体重・リーチ |

説明は短い1文を基本とし、注意事項は必要な箇所だけに置く。出典の詳細・補足・研究条件は折りたたむ。重要な医療上の限界は折りたたまず表示する。本文の専門的な情報量はこの短文化の対象とは別に扱う。

## 配色・レイアウト

白系の面、濃い文字、深緑のリンクと選択状態を共通化。新規トークンはpaper `#fafaf7`、ink `#1d2926`、accent `#195746`。特定サイトの配色値やCSSの複製ではない。ブランドの主張より表・出典の読みやすさを優先する。

## 採録上の重要な修正

旧standalone記事・bootstrapには、写真や一般的な傾向からの推定体格と、出典のない平均が含まれていた。独立した「理想体型」表示を撤回し、元記事パスには撤回の説明を残す。旧内容はGit履歴以外の表示経路から除く。

例：楢﨑智亜の身長169cm（JMSCA）と170cm（JOC2018）は両方を保存する。安楽宙斗の2024年掲載値168cm・180cmからの差+12cmは計算値であり、現在の実測値とはしない。Sean McCollの「+5 ape」は単位未記載のためcmやリーチへ変換しない。

Will BosiのExcaliburは登攀日2025-02-03と番組公開日2025-02-08を分離する。Captain NemoのAdam Ondra登攀はフラッシュ失敗後の再登で、同じ記事の別課題のフラッシュと混同しない。

## 検証と公開方式

静的出力は `npm run build` → `dist/`。本文はJavaScriptなしで存在し、JSON/CSVも生成する。main/rootおよび旧docsの互換公開ではESモジュールで同じ画面を描画し、JSON/CSVは端末内で生成する。ユーザーデータのサーバー送信はしない。既存の公開設定は変更しない。
