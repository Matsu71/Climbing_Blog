# 追加テーマ候補バックログ

既存の主要テーマ（身体・能力、力学、怪我、ジム、競技課題、高難度アウトドア、トレーニング、初心者向け）以外で、一般クライマーにとって実用性・関心が高い候補。

## 優先度A

### 1. クライミングシューズ・ギア
- シューズの形状、剛性、ダウントゥ、非対称性、ラバーの違い
- 足型とシューズ選び
- ボルダー / リード / スラブ / 強傾斜での違い
- チョーク、ブラシ、クラッシュパッド
- ハーネス、ビレイデバイス、ロープ等

単なる商品レビューより、「どんな特徴がどんな登りに向くか」をデータ化する。

### 2. グレード体系・難易度
- V-scale / Font / French / YDS等の換算
- グレードの歴史
- インドアとアウトドアの差
- 地域差
- Grade inflation / sandbagの議論
- 同じグレードでもスタイルで体感難度が変わる理由

高難度データベースと強く連携できる。

### 3. メンタル・戦術
- 恐怖と落下
- Competition tactics
- Projecting tactics
- Rest timing
- Attempt management
- 失敗後の修正
- Beta memory
- Visualization

### 4. 外岩のコンディション
- 気温、湿度、岩温とフリクション
- 花崗岩、砂岩、石灰岩等での違い
- 季節と高難度トライ
- 風、日射、結露
- チョークと摩擦

高難度課題データと気象データを将来的に組み合わせる余地がある。

## 優先度B

### 5. 外岩の安全・倫理・アクセス
- Spotting
- Crash pad配置
- Falling zone
- 岩場アクセス
- ローカルルール
- ブラッシング
- Tick mark
- 岩の保護
- 私有地・禁止エリアへの配慮

ローカルガイドの代替ではなく、一般原則を扱う。

### 6. ルートセット
- セッターが課題をどう作るか
- 難易度調整
- ホールド配置
- ムーブ誘導
- 身長差への対応
- Competition setting
- Commercial gym setting

競技課題分析との相性が良い。

### 7. グレード別・能力別ベンチマーク
- V5 / V8 / V10 / V12等で典型的にどの程度のFinger Strength等が報告されているか
- 体重比Pull-up
- Hangboard benchmark
- 柔軟性
- 経験年数

因果関係ではなく、分布・参考値として提示する。

### 8. クライミング人口・市場・文化
- 競技人口
- ジム数
- 国別普及
- オリンピック前後の変化
- ジムの開閉店推移
- 高難度課題数の増加

ジムDBや競技DBから派生できる。

## 優先度C

### 9. 栄養・体重管理
- エネルギー不足
- RED-S
- タンパク質
- 炭水化物
- トレーニング前後の食事
- 減量とパフォーマンスのトレードオフ

体型分析と関連するため、体重を軽くすることを安易に推奨しない。

### 10. 年齢とクライミング
- 子ども・ジュニア
- 成人
- 40代以降
- 加齢と筋力・腱・回復
- 年齢別トレーニング

### 11. 女性クライマー特有のテーマ
- 月経周期とパフォーマンスに関する研究
- RED-S
- 妊娠・産後復帰
- 女性競技データ

一般論と個人差を区別し、医学的内容は慎重に扱う。

## 方針

すべてを同時に作らず、既存データベースから派生できるものを優先する。

優先順位は、
1. 読者の関心
2. データを集められるか
3. 独自性
4. 他テーマとの再利用性
5. 更新コスト
で決める。
