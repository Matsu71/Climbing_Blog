# コンテンツロードマップ

## A. クライマーの身体・能力分析

### A1. フリークライミングに最適な体型・体重はあるか
主軸記事。理論だけで結論を出さず、トップクライマーの実データと科学的背景を組み合わせる。

最低4区分：
1. Outdoor Boulder
2. Outdoor Route / Sport Climbing
3. Competition Boulder
4. Competition Lead

Speed Climbing は原則対象外。

分析候補：
- 身長、体重、BMI、Ape Index
- 男女別
- カテゴリー別
- World Elite / Elite / High-level / Popular・Notable の区分
- 最高グレード、World Cup / World Championships 等の成績
- 身長ごとの体重分布
- 高い競技能力と体格の関係
- 外岩と競技で求められる体型の違い

注意：相関と因果を分ける。トップ層に多い体型を、そのまま全クライマーの「最適体重」と断定しない。

## B. クライミングの力学・保持力

### B1. 「保持力」とは何か
保持力という日常語を、可能な範囲で構成要素に分解する。

- 指屈筋群が発揮する力
- 腱・腱鞘・プーリーにかかる負荷
- ホールドとの摩擦
- 接触面積
- 手指姿勢
- 手首角度
- 肩・肩甲帯・体幹による力の伝達
- 足で荷重を逃がす能力
- 重心位置
- 壁角度

「指の最大筋力」だけを保持力とみなさない記事にする。

### B2. クリンプとオープンハンドの力学
- Open Hand
- Half Crimp
- Full Crimp
- Drag
- Pinch
- Sloper

各姿勢について、発揮しやすい力、関節角度、負荷の集中、ホールド形状との相性を整理する。

### B3. ホールドを保持できる条件を物理で考える
- 摩擦力
- 法線力
- 重力
- モーメント
- 重心
- 接触面積
- 壁角度
- ホールド方向

数式だけでなく、クライマーが直感的に理解できる図解を重視する。

### B4. なぜ足を使うと指が楽になるのか
荷重分散と身体のモーメントから説明する。

### B5. リーチ、Ape Index、身長は本当に有利か
身体データ分析シリーズと連携。

## C. 怪我・障害

### C1. クライミングの怪我はどこに多いのか
疫学研究を使い、部位別・競技別・経験レベル別に整理する。

候補部位：
- 指
- 手首
- 肘
- 肩
- 背中
- 膝
- 足首
- 足部

### C2. クライマー特有の指の怪我総覧
候補：
- Finger pulley injury
- Flexor tendon injury
- Tenosynovitis / tendon sheath irritation
- Capsulitis / synovitis
- Collateral ligament injury
- Lumbrical-related injury
- Growth plate injury（若年者）
- Bone stress / fracture 等

各記事は「症状だけで自己診断する」構成にせず、鑑別の考え方と医療機関を受診すべきサインを扱う。

### C3. A2/A4プーリー損傷とは何か
クライマーに馴染みの深い代表テーマ。解剖、負荷機序、典型的発生状況、評価、保存療法、復帰判断を研究ベースで整理する。

### C4. 肩の怪我
- 腱板関連
- 不安定性
- 上腕二頭筋長頭腱周辺
- 関節唇関連
- 過負荷による痛み

クライミング特有のオーバーヘッド姿勢と関連付ける。

### C5. 肘・前腕の怪我
- 内側 / 外側の腱障害
- 指屈筋群の過負荷
- トレーニング量との関係

### C6. 足首・膝・足部の怪我
- ボルダリングの着地
- ヒールフック等での膝負荷
- クライミングシューズと足部症状

### C7. トップクライマーはどこを怪我しているのか
公開情報からプロ・トップ選手の怪我をデータ化する。

例として保存する項目：
- 選手名
- 性別
- 年齢 / 当時年齢
- 主カテゴリー
- 怪我の年月
- 部位
- 診断名（本人・公式情報で確認できる場合）
- 怪我の状況
- 競技 / 外岩 / トレーニング
- 動作・課題タイプ
- 手術の有無
- リハビリ概要
- 復帰までの期間
- 復帰後のパフォーマンス
- 一次情報URL
- 二次情報URL
- 情報の信頼度

これにより「プロの怪我の割合」を単純な件数だけでなく、部位・種目・発生状況別に可視化できるようにする。

### C8. 怪我をどう判断するか
記事では診断行為ではなく、
- 急性か慢性か
- 明確な外傷音・腫脹・内出血の有無
- 荷重可能性
- 可動域
- 痛みの再現条件
- 医療機関を受診すべき兆候
- 画像検査が使われる場面
など「評価の考え方」を解説する。

### C9. 治療・リハビリ・復帰
怪我ごとに、
1. 初期対応
2. 医学的評価
3. 保存療法 / 手術適応
4. リハビリ
5. 負荷の再導入
6. クライミングへの復帰
7. 再発予防
を統一フォーマットで整理する。

## E. 日本のクライミングジム・データベース

### E1. 日本にはクライミングジムが何件あるのか
国内の営業中施設をできるだけ網羅し、都道府県・市区町村別に集計する。

### E2. 全国クライミングジム地図
- 緯度・経度
- 営業状態
- Boulder / Lead / Top Rope
- 施設規模
- 設備
- 評価
等から検索できる地図を作る。

### E3. 年別の開店・閉店推移
各施設の開店年・閉店年を調査し、年ごとの
- 開店数
- 閉店数
- 純増減
- 年末営業施設数
を可視化する。

### E4. ジム規模・設備比較
- 施設床面積
- クライミングエリア面積
- 壁面積
- 最大壁高
- ボルダー / リード設備
- MoonBoard / Kilter Board / Campus Board等
を可能な範囲で整理する。

### E5. 評価・口コミ
ブログ独自の5段階評価と口コミを検討する。将来的には課題・ルートの質、初心者向け、上級者向け、設備、清潔さ、アクセス等も評価軸にできる。

Google Maps評価を併記する場合はスクレイピングして自前DBへ複製するのではなく、Places API等の正規手段と帰属表示要件を使う。独自評価とは明確に分離する。

詳細設計：`project-docs/gym-database-design.md`

## F. 競技ボルダー課題・トレンド分析

### F1. 公式大会課題データベース
World-level、World Championships、Continental Championships / Series等を対象に、公式大会映像から課題単位でデータ化する。

### F2. 課題に必要な能力を多軸数値化
0〜5等で以下を別々に採点する。
- Finger / Grip Demand
- Pulling Strength
- Compression Strength
- Contact Strength / Explosive Power
- Body Tension / Core
- Lower-body Power
- Balance
- Footwork
- Mobility / Flexibility
- Coordination
- Technical Complexity
- Power-Endurance

フィジカルを保持力と完全に一体化せず、保持、引く力、コンプレッション、瞬発、体幹等に分ける。後から相関が強ければ統合指標も作れるようにする。

### F3. コーディネーションを細分化
- Upper-body coordination
- Hand-foot coordination
- Whole-body coordination
- Run / Jump / Parkour
- Redirect / Momentum control

「コーディネーション課題」という一語で終わらせず、どの身体部位・運動連鎖が要求されるかを記録する。

### F4. 壁とホールドを定量化
- 壁角度
- 実効角度
- slab / vertical / overhang / roof
- wall geometry
- crimp / sloper / pinch / volume / macro / dual-texture等
を保存する。

### F5. 課題そのものと選手ベータを分離
課題側には要求能力を保存し、選手側には実際に使ったムーブ、代替ベータ、成功・失敗、トライ数等を保存する。同じ課題でも身長・性別・選手スタイルでベータが変わることを前提にする。

### F6. 年代トレンド分析
年ごとに、
- 平均壁角度
- スラブ比率
- 強傾斜比率
- coordination score
- grip demand
- balance
- body tension
- dynamic move率
- parkour系ムーブ率
- トップ率 / フラッシュ率
等を集計する。

男女別、地域別、大会レベル別にも比較する。

### F7. AI映像分析
AIで一次分類し、重要大会・決勝課題を中心に人間監査する。
- ai_confidence
- reviewer_status
- taxonomy_version
を保存し、分類ルールが変わった場合に再分析できるようにする。

### F8. 初期対象
最初は直近5〜10シーズンのWorld-level Boulder Finalsを優先し、100〜300課題程度を高品質に整備する。その後Semifinal、Qualification、Continental Championshipsへ広げる。

詳細設計：`project-docs/competition-boulder-trend-analysis.md`

## G. 高難度アウトドアクライミング・データベース

### G1. 高難度ボルダー年表
年ごとに、
- 新たに初登されたV14+ / V15+ / V16+課題数
- その時点の最高提示グレード
- 現在のコンセンサスで見た最高グレード
- 歴史的な初登
- 各グレードを登った累計クライマー数
を可視化する。

### G2. 高難度クライマーの時系列ランキング
単一の総合点だけではなく、
- 最高完登グレード
- V17+ / V16+ / V15+ / V14+完登数
- 高難度初登数
等を表示する。各年末時点の実績を保存し、ランキングの歴史的推移を見られるようにする。

### G3. 世界高難度課題マップ
世界地図上に課題を表示し、Grade、初登年、国、岩場、岩質、スタイル、初登者等で絞り込めるようにする。アクセス上の問題がある場所では正確な座標を公開しない。

### G4. 岩・ライン・スタイル分析
岩質、壁角度、ライン形状、crimp / compression / roof / slab / dyno / technical等をタグ化し、高難度化と課題スタイルの関係を分析する。

### G5. グレード履歴と再登
初登時グレード、現在のコンセンサス、downgrade / upgrade / disputed等を分離して記録する。また、初登から最初の再登までの期間や確認済み再登者数も保持する。

### G6. 動画・一次情報
YouTube等の動画リンク、クライマー本人の発信、信頼できるクライミングメディア等を課題・登攀記録に紐付ける。映像や写真は原則リンクまたは正規埋め込みとし、無断再配布しない。

### G7. 初期対象
まずBoulder V16+を高精度に整備し、次にV15、V14へ広げる。ボルダーのスキーマが安定後、Outdoor Leadの9b+、9a+、9a等へ拡張する。

詳細設計：`project-docs/outdoor-hard-climbing-database.md`
