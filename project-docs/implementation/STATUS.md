## 品質の境界
- 情報の公表日と確認日を分離する。
- 不明値は null。現在のコンセンサスや再登総数を推測しない。
- 医療情報は一般情報。診断・治療・復帰の個別処方をしない。
- 競技の要求スコアは観察者の仮評価。実測や公式評価と混同しない。
- 個人用メモは明示的な操作で端末内に保存する。

既存構想の達成度、実装・テスト・残課題はリリース時の検証記録に記載します。
