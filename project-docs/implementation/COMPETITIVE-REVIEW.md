# 競合比較と実装への反映 — 2026-09-11

## 調査の範囲

運営者の公開機能説明・公開ページを確認しました。有料機能を含む全アプリの実機比較、利用者への比較試験、市場シェア評価は行っていません。「既存のどのサービスより優れている」と結論づける資料ではありません。

## 読者の問いと実装

| 読者の問い | 今回の実装 | 確認方法 |
|---|---|---|
| 「スローパーが持てない理由を知りたい」 | かな・全半角を吸収する横断検索、結論を先にした記事、力学の教材 | 検索→該当記事、入力リセット、保存、関連記事をブラウザーで検証 |
| 「ボルダーとリードがある施設を比べたい」 | 種目・地域・ブランドの絞り込み、最大3施設の比較 | 両種目へのフィルター一致、URL復元、選択上限を検証 |
| 「紹介されていたジムはまだある？」 | 営業案内と閉店履歴を区別。公式確認日を表示 | 閉店施設を初期一覧から分離し、閉店日と出典を確認 |
| 「ベータやフラッシュとは何？」 | 28語の短い定義、混同しやすい点、関連記事 | 全文検索と記事・用語間の移動を検証 |
| 「今日できなかったことを次に活かしたい」 | トライノートの観察・次の一手、JSONバックアップ | 保存前は書き込まない、編集・復元・壊れた入力の拒否を検証 |
| 「怪我の記事を信用してよい？」 | 根拠、研究の限界、専門家未監修の表示 | 出典への導線と注意表示を検証。医学的監修は未完了 |

## 次の改善を受け入れる条件

最終目標は、個々の機能が動くことだけでは達成しません。次の領域は実測値と監査記録が必要です。

1. **一般公開**：対象コミットのデプロイが成功し、公開URLでページと主要操作を確認する。
2. **高難度の充実**：初登記録だけでなく、確認可能な再登・本人のグレード意見・日付精度・更新履歴を持つ。ランキングには収録範囲を表示する。
3. **ジムの充実**：複数運営元・地域へ拡張し、閉店・移転・改名を追跡。開店日が足りないまま全国の時系列統計を作らない。
4. **専門性**：医療・負荷管理は専門家レビューを受ける。体格データから減量や理想体重を自動推奨しない。
5. **使いやすさの比較**：一般クライマーが検索、比較、出典確認、ノート保存を行い、到達時間・失敗・分かりにくい語を測る。競合と同じ条件で比較し、架空の満足度を作らない。
6. **面白さの確認**：読者が「もっと知りたい」と進んだ記事・比較軸を、本人の同意を得た試験で確かめる。追跡のための外部アクセスを無断追加しない。

継続改善の優先度は、資料や記事の件数だけではなく、これらの問いを根拠付きで解決できるかで判断します。
