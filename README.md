# CRUX — Climbing Blog

**登るほど、知りたくなる。** 一般クライマーの「知りたい・比較したい・次に試したい」をつなぐ、日本語のクライミング情報サイトです。

元の構想を省略せず、[当初のREADME全文](project-docs/original-brief.md)へそのまま保存しています。[最終目標](project-docs/site-vision.md)は変えていません。世界最高水準は改善目標であって、達成済みという自己評価ではありません。

## 実装済みの入口

| 入口 | 内容 |
|---|---|
| 読む | 22本の解説、結論→詳細→出典、関連記事と用語への接続 |
| 高難度記録 | 14件の歴史的記録、検索・年表・最大3件の比較、9人の索引 |
| ジムを選ぶ | 21施設、場所・種目・運営元・状態の絞り込み、最大3施設の設備比較 |
| 用語を引く | 日本語・英語で検索する28語、短い定義と混同しやすい点 |
| トライノート | 観察と次に試すことを端末内保存。編集・検索・JSONバックアップ |
| 学ぶ・試す | 研究5件、12問の解説付きクイズ、力学模型と計算・予定整理ツール |

ジムの21施設は、公式の営業案内がある18施設と閉店履歴3施設です。全国網羅・本日営業中・施設のおすすめ順位を意味しません。課題の現在グレードや再登総数、人物の身体数値も、未確認なら未確認のまま表示します。

## 起動と検証

Node.js 22以上を使用します。サイト本体に外部npm依存はありません。

```sh
npm run check
npm run serve
# http://127.0.0.1:4173/Climbing_Blog/
```

`npm run check` は、データ・計算のテスト、静的ページ生成、内部リンク検査を実行します。生成先は `dist/` です。

実ブラウザーの検証は次のとおりです。PythonとPlaywrightはテスト用で、本番サイトには含みません。

```sh
python -m pip install 'playwright==1.58.0'
python -m playwright install --with-deps chromium webkit
python -m unittest discover -s tests -p 'test_*.py'
python tests/browser_smoke.py
python tests/webkit_smoke.py
```

GitHub Actionsの **Verify CRUX** が同じ検証を行い、ソース・生成サイト・JSONの結果・スマートフォン幅のスクリーンショットを保存します。WebKitの自動検証は、物理的なiPhone実機テストとは区別します。

## 公開

**ソースの統合、テストの成功、一般公開は別の状態です。** 公開状態は、Actionsの `Check publishing configuration` と `Publish verified site` を確認してください。公開されていない状態を「公開済み」と表示しません。

[GitHub Pagesの初回設定・公開・復旧手順](project-docs/implementation/DEPLOYMENT.md)

`main` では検証を通過した同じ `dist/` だけを公開用に梱包します。Pagesの初回有効化や公開元の変更を、テスト用の権限で勝手に行うことはありません。

## 保存データとプライバシー

トライノートは明示的な保存操作で、このブラウザーの `localStorage` に保存します。最大250件です。クラウド送信・端末同期・アカウント機能はありません。JSONの読み込みは最大1MB、同じIDは上書きせず、破損した入力は全件拒否します。

別タブで更新された編集対象の検知、保存領域が使えない場合の案内、元データを破損させない取り扱いを実装しています。ただしブラウザーの保存データ削除に備え、重要な記録は書き出してください。他サイト・他アプリの保存キーは削除しません。

## 構成

- `data/`：公開出典・記事・記録・施設・用語の元データ
- `src/`：静的ページ生成、共通計算・入力検証
- `public/`：ブラウザー側の操作とスタイル。外部への自動リクエストなし
- `scripts/`：ビルド・ローカルサーバー・リンク検査・公開状態確認
- `tests/`：データ・計算・公開状態・Chromium・WebKitの検証
- `project-docs/`：元の構想、根拠の扱い、競合比較、残課題
