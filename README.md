# Climbing Blog

クライミングに関するデータ・科学・実践知をまとめる個人プロジェクトです。趣味目的を中心としつつ、可能な限り一次情報・競技データ・学術研究を参照し、一般のクライマーにも分かりやすい形で整理します。

## 主なテーマ

### 1. クライマーの身体・能力分析
- フリークライミングに適した体型・体重はあるか
- Outdoor Boulder / Outdoor Route / Competition Boulder / Competition Lead の比較
- トップ選手、有名クライマー、ハイレベルクライマーを区別して分析
- 身長、体重、BMI、Ape Index、競技実績、最高グレード等のデータ化
- 男女差、カテゴリー差、身長別の体重分布などを分析

### 2. クライミングの力学・保持力
- そもそも「保持力」とは何か
- 指・前腕・肩・体幹がホールドに力を伝える仕組み
- オープンハンド、ハーフクリンプ、フルクリンプ等の違い
- ホールド形状、摩擦、接触面積、壁角度、重心、モーメントなどの物理的分析
- 「強い指」だけでは説明できないクライミング動作の力学

### 3. 怪我・予防・復帰
- クライミングで特徴的な指の怪我
- 肩、肘、手首、足首、膝などの怪我
- トップクライマー・プロ選手の怪我事例データ
- 怪我の部位、種類、発生状況、復帰期間等を構造化
- 医学文献に基づく評価方法、受診目安、治療・リハビリ・復帰の考え方

### 4. 日本のクライミングジム
- 日本国内のクライミングジムを可能な限り網羅
- 全国地図上でジムの場所を表示
- 年別の開店数・閉店数・営業施設数の推移を分析
- 都道府県・市区町村別の施設数や密度を可視化
- 面積、壁高、Boulder / Lead / Top Rope設備、料金、トレーニング設備等を整理
- ブログ独自のユーザー評価・口コミ機能を検討
- Google Maps評価を利用する場合はPlaces API等の利用条件と帰属表示に従い、独自評価とは分離して表示

### 5. 競技ボルダー課題・トレンド分析
- World-level、Continental Championship / Series等の公式大会映像を基に課題をデータ化
- 1課題を単一カテゴリではなく、保持力、上半身筋力、コンプレッション、瞬発力、ボディテンション、バランス、足技、可動域、コーディネーション等の複数軸で数値化
- コーディネーションを上半身、手足連動、全身連動、ラン・ジャンプ、方向転換等に細分化
- 壁角度、壁形状、ホールド種類、主要ムーブ、トップ率・フラッシュ率等を保存
- 課題そのものの要求能力と、各選手が実際に使ったベータを分離して記録
- 年別・男女別・地域別・大会レベル別に課題傾向を分析し、現代競技クライミングの変化を可視化

## 編集方針

- 科学的根拠、実データ、経験談を混同しない
- 選手データは出典と取得時点を保存する
- 医療情報は診断を断定せず、研究・レビュー・専門機関等の根拠を明示する
- 「軽いほど強い」「痛みが消えれば治癒」など単純化しすぎた結論を避ける
- 施設データは公式情報・一次情報を優先し、開店・閉店や面積等の根拠と確認日を保存する
- 競技課題のAI分類は主観が入るため、分類定義・taxonomy version・AI confidence・人間監査状態を保存する
- 一般クライマーが実際に利用できる分かりやすさを優先する

詳細な企画は `project-docs/` を参照してください。
