# Climbing Blog

クライミングに関するデータ・科学・実践知をまとめる総合情報サイト・個人プロジェクトです。

## 最終目標

一般のクライマーが「クライミングについて何か調べたいとき、とりあえずここを見る」と思えるサイトを目指します。

ローカル岩場情報を完全網羅することよりも、インターネット上に公開されている競技記録、選手情報、高難度課題、ジム情報、学術研究、公式情報等を可能な限り収集・整理・検証し、記事、データベース、ランキング、グラフ、年表、地図等として分かりやすく提供することを重視します。

目標は、クライミング関連サイトの中で、分かりやすさ、使いやすさ、データ整理、可視化、出典の明確さ、一般クライマーへの実用性について世界最高水準を目指すことです。

初心者向け記事も用意しますが、サイトの中心ユーザーはすでにクライミングをしている一般クライマーです。

## 主なテーマ

### 1. クライマーの身体・能力分析
- フリークライミングに適した体型・体重はあるか
- Outdoor Boulder / Outdoor Route / Competition Boulder / Competition Lead の比較
- トップ選手、有名クライマー、ハイレベルクライマーを区別して分析
- 身長、体重、BMI、Ape Index、競技実績、最高グレード等のデータ化
- 男女差、カテゴリー差、身長別の体重分布などを分析

### 2. クライミングの力学・保持力
- そもそも「保持力」とは何か
- 指・前腕・肩・体幹がホールドに力を伝える仕組み
- オープンハンド、ハーフクリンプ、フルクリンプ等の違い
- ホールド形状、摩擦、接触面積、壁角度、重心、モーメントなどの物理的分析
- 「強い指」だけでは説明できないクライミング動作の力学

### 3. 怪我・予防・復帰
- クライミングで特徴的な指の怪我
- 肩、肘、手首、足首、膝などの怪我
- トップクライマー・プロ選手の怪我事例データ
- 怪我の部位、種類、発生状況、復帰期間等を構造化
- 医学文献に基づく評価方法、受診目安、治療・リハビリ・復帰の考え方

### 4. 日本のクライミングジム
- 日本国内のクライミングジムを可能な限り網羅
- 全国地図上でジムの場所を表示
- 年別の開店数・閉店数・営業施設数の推移を分析
- 都道府県・市区町村別の施設数や密度を可視化
- 面積、壁高、Boulder / Lead / Top Rope設備、料金、トレーニング設備等を整理
- ブログ独自のユーザー評価・口コミ機能を検討
- Google Maps評価を利用する場合はPlaces API等の利用条件と帰属表示に従い、独自評価とは分離して表示

### 5. 競技ボルダー課題・トレンド分析
- World-level、Continental Championship / Series等の公式大会映像を基に課題をデータ化
- 1課題を単一カテゴリではなく、保持力、上半身筋力、コンプレッション、瞬発力、ボディテンション、バランス、足技、可動域、コーディネーション等の複数軸で数値化
- コーディネーションを上半身、手足連動、全身連動、ラン・ジャンプ、方向転換等に細分化
- 壁角度、壁形状、ホールド種類、主要ムーブ、トップ率・フラッシュ率等を保存
- 課題そのものの要求能力と、各選手が実際に使ったベータを分離して記録
- 年別・男女別・地域別・大会レベル別に課題傾向を分析し、現代競技クライミングの変化を可視化

### 6. 世界の高難度アウトドアクライミング
- 高難度ボルダーと高難度リードを世界規模でデータベース化
- 何年にどのグレードが初登されたかを年表化し、最高難度の歴史的変化を可視化
- V16以上などの高難度完登数、最高グレード、初登数等からクライマーの時系列ランキングを作成
- 初登時グレードと現在のコンセンサスを分離し、降格・異論・未再登等も記録
- 世界地図上に高難度課題を表示し、国・岩場・岩質・傾斜・スタイル・年代で絞り込み
- 岩の形、岩質、課題スタイル、初登者、再登者、動画リンク等をまとめる
- ローカル岩場ガイドの代替ではなく、高難度帯の歴史・人物・地理・スタイル分析に集中する

### 7. トレーニング・強くなる方法
- 最適なクライミング頻度は週何日か
- Finger Strength、Contact Strength、Pulling Strength、Compression、Body Tension等を分解して考える
- Hangboard / Fingerboardの使い方、頻度、強度
- Campus Boardの目的と適用条件
- Limit Boulder、筋力トレーニング、Power、Power-Endurance、持久力
- 足技、重心移動、Heel Hook、Toe Hook、Coordination等のテクニック
- 柔軟性・可動域
- セッション設計、休養、睡眠、栄養、Deload
- Projecting、高難度課題への取り組み方
- 初心者・中級者・上級者で必要なトレーニングを分けて整理
- 研究データとコーチ・選手の経験則を区別する

### 8. 初心者向け
中心コンテンツではありませんが、初めてジムへ行く人にも入口を用意します。

例：
- 初めてクライミングジムへ行く前に知ること
- ボルダリングのルールと安全
- グレードの読み方
- 最初の3か月で意識すること
- シューズ、チョーク等の最低限の道具

## サイト設計方針

- 記事だけで終わらせず、可能なものはJSON / CSV等の再利用可能な構造化データとして保持する
- 同じ元データから記事、一覧、ランキング、グラフ、年表、比較ページ、地図を生成できる構成を目指す
- モバイルで見やすく、検索・絞り込み・並べ替えを重視する
- 一般クライマーが最初に知りたい結論を先に示し、必要に応じて詳細へ掘り下げられる構造にする

## 編集方針

- 科学的根拠、実データ、経験談を混同しない
- 選手データは出典と取得時点を保存する
- 医療情報は診断を断定せず、研究・レビュー・専門機関等の根拠を明示する
- 「軽いほど強い」「痛みが消えれば治癒」「週○日が全員に最適」など単純化しすぎた結論を避ける
- 施設データは公式情報・一次情報を優先し、開店・閉店や面積等の根拠と確認日を保存する
- 競技課題のAI分類は主観が入るため、分類定義・taxonomy version・AI confidence・人間監査状態を保存する
- アウトドア課題のグレードは評価であることを前提に、初登時グレード、現在のコンセンサス、異論、情報源を分離して保存する
- 岩場位置はアクセス上の配慮を行い、公開に問題がある正確な座標は掲載しない
- トレーニング情報では研究結果と経験則を分離し、レベル、目的、怪我歴、回復能力等の条件を明示する
- 一般クライマーが実際に利用できる分かりやすさを最優先する
