# Climbing Blog

クライミングに関するデータ・科学・実践知をまとめる個人プロジェクトです。趣味目的を中心としつつ、可能な限り一次情報・競技データ・学術研究を参照し、一般のクライマーにも分かりやすい形で整理します。

## 主なテーマ

### 1. クライマーの身体・能力分析
- フリークライミングに適した体型・体重はあるか
- Outdoor Boulder / Outdoor Route / Competition Boulder / Competition Lead の比較
- トップ選手、有名クライマー、ハイレベルクライマーを区別して分析
- 身長、体重、BMI、Ape Index、競技実績、最高グレード等のデータ化
- 男女差、カテゴリー差、身長別の体重分布などを分析

### 2. クライミングの力学・保持力
- そもそも「保持力」とは何か
- 指・前腕・肩・体幹がホールドに力を伝える仕組み
- オープンハンド、ハーフクリンプ、フルクリンプ等の違い
- ホールド形状、摩擦、接触面積、壁角度、重心、モーメントなどの物理的分析
- 「強い指」だけでは説明できないクライミング動作の力学

### 3. 怪我・予防・復帰
- クライミングで特徴的な指の怪我
- 肩、肘、手首、足首、膝などの怪我
- トップクライマー・プロ選手の怪我事例データ
- 怪我の部位、種類、発生状況、復帰期間等を構造化
- 医学文献に基づく評価方法、受診目安、治療・リハビリ・復帰の考え方

## 編集方針

- 科学的根拠、実データ、経験談を混同しない
- 選手データは出典と取得時点を保存する
- 医療情報は診断を断定せず、研究・レビュー・専門機関等の根拠を明示する
- 「軽いほど強い」「痛みが消えれば治癒」など単純化しすぎた結論を避ける
- 一般クライマーが実際に利用できる分かりやすさを優先する

詳細な企画は `project-docs/` を参照してください。
